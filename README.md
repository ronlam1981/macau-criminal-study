# 澳門刑法研習室

沿用澳門民法研習室的學習架構，以官方刑法典整合文本及修訂來源整理。

網站：https://ronlam1981.github.io/macau-criminal-study/

- 355個條號、354個課程項目。
- 30課淺白解說、例子、反例，708題情境及原文辨認測驗。
- 本機進度、筆記、收藏、錯題與間隔複習，支援JSON備份。
- 非官方學習網站，原文與教材分開；相關特別法另有官方入口。

## 部署

GitHub Pages：Deploy from a branch → main → / (root)。
